Getting started
  • Each consumable is a card · + New card picks the type · click a card to edit it
  • Inventory cards: tap − / + to change what’s on hand · info cards: what goes where
  • Frames group categories · drag a card onto another’s bottom edge to tuck in a note
  • Right-click anything for options · File to export, import or print · ? for shortcuts
