Getting started
  • Double-click the board for a new note · click a note to edit, double-click to type on it
  • Drag a note onto another’s bottom edge to stack it (up to 4 levels)
  • Drag the blue dot on a note’s edge to draw an arrow · ▭ makes a frame to group notes
  • Right-click anything for options · File ▾ to export, import or print · ? for shortcuts
