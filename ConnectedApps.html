Connect Claude

Add Machine Manager to Claude as a custom connector with this address. Claude asks you to sign in here once, then reads your organizations' mill data and document library with the same access you have, read-only.

  1. On claude.ai (a phone's browser works): Settings → Connectors → Add custom connector.
  2. Name it “Machine Manager (signed in)”, paste the address, leave the OAuth fields blank, and add it.
  3. Choose Connect: this page opens; check the account and Approve.
