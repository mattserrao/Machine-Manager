Ground rules

Every row has a positionBUS items, WOs, RCFAs, vendor findings and document chunks all carry a PM1 position id from My Machine. That key is what lets an outage brief pull everything for "2nd press felt".
Tables first, search secondAnything with rows and columns goes in a table and is answered with a query. Only narrative text (report findings, RCFA write-ups, manuals) is chunked and embedded for search.
Pi stays in PiTrends are read on demand from the historian. Only Envoy exceptions are stored, as dated events.
Models are swappablePrompts and tools live in this app, not in a vendor's features. The adapter maps one request format to each provider; embeddings record which model made them.
Answers cite recordsEvery statement links back to the row, page or trend it came from, so it can be checked before it goes on an outage plan.
