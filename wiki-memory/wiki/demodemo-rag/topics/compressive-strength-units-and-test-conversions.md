- Compressive strength = load at which failure occurs under edgewise compressive forces; expressed per width, or per width per basis weight (compressive index per TAPPI/ISO) [DOC 168553e0-baa3-4e06-827d-54415678796a p.56]
- "lb x 4.448 = Newtons (N)" [DOC 168553e0-baa3-4e06-827d-54415678796a p.56]
- "lb/inch x 0.1790 = kilogram force/centimeter (kg/cm)" [DOC 168553e0-baa3-4e06-827d-54415678796a p.56]
- "lb/inch x 0.17513 = kilo-Newtons/meter (kN/m)" [DOC 168553e0-baa3-4e06-827d-54415678796a p.56]
- "(lb/inch)/(lb/1000 ft2) x 35.84 = Newton-meters/gram (Nm/g)"; "Newton-meters/gram x 0.1020 = kilometers (km)" [DOC 168553e0-baa3-4e06-827d-54415678796a p.56]
- Tensile index is tensile strength per unit basis weight [DOC 168553e0-baa3-4e06-827d-54415678796a p.56]
- Drying strain: web tension in dryers restricts MD shrinkage; cross-machine restraints also occur [DOC 168553e0-baa3-4e06-827d-54415678796a p.57]
- Methods differ (ring, modified ring, STFI strip, Concora liner test, lateral support by FPL, Weyerhaeuser, PAPRICAN); conversions are hard [DOC 168553e0-baa3-4e06-827d-54415678796a p.57]
- CD tests over a wide range of linerboard weights, results in lb/inch or kN/m: STFI = 1.436 x ring compression; STFI = 1.185 x modified ring compression; STFI = 1.135 x FPL lateral support; STFI = 1.416 x Weyerhaeuser lateral compression [DOC 168553e0-baa3-4e06-827d-54415678796a p.57]
