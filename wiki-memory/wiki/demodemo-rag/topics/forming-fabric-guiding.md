## Causes (AstenJohnson)
- Root causes: "misalignment of machine components, poor guide roll set up, issues with guide assembly, or the forming fabric design itself" [DOC 59151609-8cbd-461a-874e-aaeb006dfc27 p.1]
- Guide roll next to a stretch roll changes wrap when the stretch roll moves; short fabrics reduce wrap [DOC 59151609-8cbd-461a-874e-aaeb006dfc27 p.2]
- Low or non-uniform tension: palm does not pick up movement, fabric slips on the guide roll [DOC 59151609-8cbd-461a-874e-aaeb006dfc27 p.2]
- Flatbox/vacuum element misaligned: fabric guides one way stock-off and the other stock-on [DOC 59151609-8cbd-461a-874e-aaeb006dfc27 p.4]
- Drilled suction box cover holes matching fabric twill pattern [DOC 59151609-8cbd-461a-874e-aaeb006dfc27 p.4]

## Remedies and numbers
- Fourdrinier wrap angle at least 25 deg [DOC 59151609-8cbd-461a-874e-aaeb006dfc27 p.3]
- Polyamide CD yarns lose about 30% friction vs polyester; wrap and tension matter more [DOC 59151609-8cbd-461a-874e-aaeb006dfc27 p.3]
- Palm too sensitive picks up normal oscillation; too dull misses walking; tune spring tension, pneumatic settings, vent orifice, system air pressure [DOC 59151609-8cbd-461a-874e-aaeb006dfc27 p.3]
- Strong continuous corrections cause excess fabric wear and shorter life [DOC 59151609-8cbd-461a-874e-aaeb006dfc27 p.2]
- TruTrac: patented balanced machine-side twill so stock on/off forces cancel [DOC 59151609-8cbd-461a-874e-aaeb006dfc27 p.3]
- Older Paper Machine Clothing checklist lists the same family: suction box vacuum, palm sensitivity, front-to-back tension, wrap/lead-in/lead-out, drive synchronization [DOC 004f7fc0-956b-4eb3-aa93-df1adf3f0adf p.3]
