## Definitions
- Time efficiency: percentage of time the machine is available for operation [DOC 30d870b7-8b32-475a-9f65-e8f3bd87bd7b p.9]
- Operational efficiency: on-grade tonnage produced as a percentage of what could be produced at the same speed in the available time [DOC 30d870b7-8b32-475a-9f65-e8f3bd87bd7b p.9]
- Absolute efficiency: product of time and operational efficiency; equals on-grade production as a percentage of theoretical production in all hours the mill is open, maintenance included [DOC 30d870b7-8b32-475a-9f65-e8f3bd87bd7b p.9]
- "The only parameter that really matters is absolute efficiency"; be wary of undefined efficiency figures [DOC 30d870b7-8b32-475a-9f65-e8f3bd87bd7b p.9]
- Trim efficiency: sheet width actually cut into rolls vs total salable width; mainly under production planning control [DOC 30d870b7-8b32-475a-9f65-e8f3bd87bd7b p.9]
- Speed is proportional to production if all else unchanged; a machine should run in the speed range that maximises production (Figure 21-1) [DOC 30d870b7-8b32-475a-9f65-e8f3bd87bd7b p.9]
- Compare machines by tons per day per inch of width within the same grade [DOC 30d870b7-8b32-475a-9f65-e8f3bd87bd7b p.9]
- Machines usually run near the theoretical maximum set by the drive or by dryer capacity; if speed limited and efficient at the ceiling, upgrading drives is usually justifiable [DOC 30d870b7-8b32-475a-9f65-e8f3bd87bd7b p.10]

## Daily efficiency formula
- "% = (accepted production / theoretical production) [100]"; accepted production is cumulative scaled product at the end of a 24-hour period [DOC 30d870b7-8b32-475a-9f65-e8f3bd87bd7b p.10]
- Theoretical production = (speed)(machine trim)(grammage)(elapsed time) in compatible units [DOC 30d870b7-8b32-475a-9f65-e8f3bd87bd7b p.10]
