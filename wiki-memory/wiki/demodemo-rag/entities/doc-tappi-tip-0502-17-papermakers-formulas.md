## Operative values (verbatim)
- Intent: equations "that can be used by paper mill superintendents and engineers during their day-to-day operation of the paper machine". [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.1]
- #2 Hydraulic pump power = H x Q / 1714 (hp; psi, gal/min) or H x Q / 60000 (kW; kPa, l/min); centrifugal: capacity ~ speed, head ~ speed squared, power ~ speed cubed. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.3]
- #3 "Screen to headbox acceptable range is 7 to 14 ft/s" (2.1 to 4.3 m/s). [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.3]
- #4 Rectangular weir Q = 3.33 x (L - 0.2 H) x H^1.5 (ft3/s); SI 1.837; L should be 4-8 times H. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.4]
- #5 Theoretical head = (V/100)^2 / K; K: in. H2O 1.9304, ft H2O 23.165, in. Hg 26.196, PSIG 53.336; SI head (m H2O) = V^2 / 70610. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.5]
- #6 Spouting velocity V = K sqrt(h); K: 139.2 (in. H2O), 481.5 (ft H2O), 513.3 (in. Hg), 732.3 (PSIG); SI V = 265.7 sqrt(h m H2O). [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.5]
- #7 Slice flow per unit width = 0.052 x V x S.O. x Cc (gal/min/in); approximate Cc: nozzle 0.95, type A 0.75, B 0.70, C 0.60. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.6]
- #9 Tissue headbox flow: throat opening times V, contraction coefficient assumed 1.0. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.6]
- #11 Ton/d = C x Q / K (English) with K 16.76 at 100 F, 16.83 at 120 F, 16.93 at 140 F; SI t/d = C x Q x 4.1727 / K. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.7]
- #12 "Retention (%) = [(Headbox Consistency - Tray Consistency) / Headbox Consistency] x 100". [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.8]
- #13 Example: 0.5 in slice, Cc 0.75 gives jet 0.375 in (0.952 cm); 50 g/m2 at 0.6% and J/W 0.95 gives retention 92.1%. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.8]
- #14 Forming length dwell time (headbox slice to first flatbox or dandy): 2.0 s below 1200 ft/min (speed supportable = forming length x 30); 1.0 s above (x 60); 42 lb liner (205 g/m2) 1.25 s (x 48); foodboard 2.0 s (x 30). The first row of the table prints 1.5 s / x 40 without a grade label. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.8]
- #15 Blade pulse frequency f = V / (k x lambda), k = 5 (ft/min, inches) or 60 (m/min, m); "typically, f > 60 cycles/sec and can be as high as 150 cycles/sec". [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.9]
- #16 Shake number = (Amplitude x Frequency^2) / Wire speed; English: benefit "over 30", "Suggested target is 50-60"; SI: benefit over 2500, target 4200-5000; above that equipment limits. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.9]
- #17 Dandy roll rpm approx wire speed / (3.142 x diameter); "Target = 125 - 150 rev/min". [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.9]
- #25 Press impulse PI = 5 x PLL / Speed (psi.s; lbf/in, ft/min) or 0.060 x PLL / Speed (MPa.s; kN/m, m/min). [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.12]
- #26 Draw % = (SF - SI)/SI x 100. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.12]
- #29 "Rimming speed (ft/min) = [5720 - (2160/D)] L^(1/3)" (D inside dryer diameter ft, L condensate film thickness ft; empirical, 5-ft and 6-ft dryers; x 0.3048 for m/min). [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.14]
- #31 Crepe has two definitions, not comparable: (Yankee - Reel)/Reel x 100, or (Yankee - Reel)/Yankee x 100. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.15]
- #32 Production off reel P = S x BW x T x 0.06 (kg/h; m/min, g/m2, trim m); x 0.024 for t/d. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.15]
- #34 Average densities (kg/m3): coated and supercalendered 1162.56, coated only 1051.84, newsprint 636.64, fine paper 802.72, linerboard 664.32, coated board 775.04. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.16]
- #35 Basis weight to g/m2: offset lb/3300 ft2 x 1.48; bond lb/1300 x 3.76; liner lb/1000 x 4.89; news and tissue lb/3000 x 1.63; market pulp lb/2880 x 1.70. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.16]
- #36 Roll rpm = 0.3183 x V / Do (m); "Maximum 250 rev/min for size press rolls". [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.16]
- #43 1 HP = 746 W; water 62.4 lb/ft3 = 8.34 lb/gal; lbf/in. = kN/m x 5.7. [DOC 2324ca0e-e2cb-4ac4-8f6c-1c90e2a03701 p.18-19]
