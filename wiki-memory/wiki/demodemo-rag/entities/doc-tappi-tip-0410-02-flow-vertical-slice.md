## Operative values (verbatim)
- Valid for ideal fluid and dilute suspensions "provided that the effects of gravity and surface tension are small and the flow is unobstructed for a distance of several times the slice opening b". [DOC dd1c4162-82cc-4158-b722-da1cfe25fa20 p.1]
- Example 1: B = 500 mm, b = 20 mm, L = 10 mm gives b/B = 0.040, L/b = +0.5, "beta = 9.0 deg", Cc = 0.62, jet "d = Cc b = 0.62 (20) = 12.4 mm". [DOC dd1c4162-82cc-4158-b722-da1cfe25fa20 p.1]
- Example 2 (curved slice, B = 28 mm, b = 20 mm, L = 16 mm): b/B = 0.71, L/b = +0.8, beta = 3.9 deg, Cc = 0.697, d = 13.9 mm. [DOC dd1c4162-82cc-4158-b722-da1cfe25fa20 p.2]
- Example 3: to cut angle from 9.0 to 5.0 deg needs L/b = +0.75, L = 15 mm; Cc = 0.618, d = 12.4 mm. [DOC dd1c4162-82cc-4158-b722-da1cfe25fa20 p.4]
- Table 1 Cc coefficients a0..a8 = 0.06461, 0.06575, 1.00162, 3.91592, 3.15442, 0.73227, 0.60597, 0.46721, 0.84737; f = 1.11253; beta coefficients b0..b10 = 158.3, 278.6, 235.9, 80.84, 439.9, 166.1, 0.7481, 2.008, 2.981, 1.389, 2.416. [DOC dd1c4162-82cc-4158-b722-da1cfe25fa20 p.5]
- "The estimated maximum errors are 0.005 for Cc and 0.20 deg for beta." [DOC dd1c4162-82cc-4158-b722-da1cfe25fa20 p.5]
- Example 4 (equations, same data): Cc = 0.618, beta = 8.97 deg. [DOC dd1c4162-82cc-4158-b722-da1cfe25fa20 p.5]
