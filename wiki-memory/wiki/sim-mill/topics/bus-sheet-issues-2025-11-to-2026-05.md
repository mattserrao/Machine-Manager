## How the BUS issue log reads
- Later period (2026-04-24 onward) is in [[bus-issue-sheet]] and [[bus-issues-2026-10-late]]; this page covers the earlier months.
- Each BUS issue is one subject on the daily BUS sheet: section / asset (asset no.), position (a My Machine position id or "-"), text, days on the sheet, last status, days open, and a day-by-day line with owner, status (New, Open, Closed) and WO. [BUS 2025-11-01 issue 92ed38f0c1854bb8]
- This batch holds 247 issues first seen 2025-11-01 to 2026-05-03; all end Closed. Later issues are in other batches. [BUS 2025-11-01 issue 92ed38f0c1854bb8] [BUS 2026-04-22 issue 23e6fd11048e3e48]
- The same subject re-opens as a new issue each time (e.g. Dryer can 13 flooding 11 issues); a WO is attached to some days only, and one issue can show two WOs. Use the per-asset pages for counts. [BUS 2026-04-21 issue 206d0fe862c59688]
- Each issue also gets an action "Follow up: ..." created the day it hits the sheet: see [[bus-follow-up-actions]]. Tool: search_records (BUS history); WO numbers via shift_reports / outage_scope. Issue ids below are the first 8 hex characters unless the full 16 are given.
