How it works

  1. Upload. The PDF goes to your organization’s private storage. An identical file already in the library is recognised and not added twice.
  2. Read. Text comes from the PDF itself; scanned, rotated or garbled pages and tables are read by Claude.
  3. Check. Each document gets a quality score (readable text, date, vendor, machine positions, whether it’s about the mill, near-duplicates). 75 or more is indexed straight away; 40–74, or anything flagged, waits for an editor; below 40 is rejected.
  4. Index. Passages are tagged with the document, date and machine positions and made searchable by words and by meaning. MM LLM and MCP agents cite them as [DOC id p.page].
